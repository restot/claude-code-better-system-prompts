Edit Jupyter notebook (.ipynb) cells.

- \`notebook_path\`: absolute path required
- \`cell_number\`: 0-indexed
- \`edit_mode=insert\`: add cell at index
- \`edit_mode=delete\`: delete cell at index
- Default: replace cell contents
